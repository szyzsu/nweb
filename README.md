
## Quick Start

Simply open `index.html` in your web browser to view the website.

### File Structure

```
nweb/
├── index.html      # Main website page
├── styles.css      # External stylesheet
├── README.md       # Project documentation
├── LICENSE         # MIT License
└── .gitignore      # Git ignore file
```

## Sections

- **Home** - Welcome message and introduction
- **About** - Information about nweb
- **Features** - Key features and capabilities
- **Contact** - Contact information

## Customization

You can easily customize the website by:
1. Editing the content in `index.html`
2. Modifying colors and styles in `styles.css`
3. Adding new sections following the existing structure

## Features

### Responsive Design
The website automatically adapts to different screen sizes:
- Desktop (1200px+)
- Tablet (768px - 1199px)
- Mobile (480px - 767px)
- Small Mobile (< 480px)

### CSS Variables
The stylesheet uses CSS custom properties for easy theming:
- `--primary-color`: Main accent color
- `--secondary-color`: Secondary accent color
- `--dark-bg`: Dark background color
- `--light-bg`: Light background color

### Performance
- Minimal dependencies
- No external frameworks or libraries
- Fast loading times
- Optimized for all devices
